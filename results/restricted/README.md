# Restricted-data provenance

Authorized controlled-access ADNI experiments motivated this repository.
Participant-level images, segmentations, identifiers, QC, regional volumes,
metrics, and single-acquisition Phase 3 artifacts remain outside public Git.

`phase2/` contains only approved condition-level means across two acquisitions.
These exploratory aggregates are not part of the OpenNeuro replication and
must not be used to infer participant-level values.
